# Prompt: Update Brain

A manual prompt to keep the `brain/` files current. Copy it into Claude Code.

---

Update my DevBrain context.

1. Ask me what has changed since the last update.
2. Edit only the `brain/` files that need it. Common targets:
   - `current-focus.md` — new priorities and in-progress work.
   - `decisions.md` — add new decisions with a short reason.
   - `projects.md` — status, challenges, next steps.
   - `coding-style.md` — changed preferences.
3. Make small, targeted edits. Do not rewrite whole files.
4. Remove anything that is now outdated. If a decision was reversed, fix or remove the old entry so it does not contradict the new one.
5. Show me a short per-file summary of what changed.
