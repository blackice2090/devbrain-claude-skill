# Prompt: Interview

A manual prompt to fill the `brain/` files for the first time. Copy it into Claude Code.

---

Interview me to set up my DevBrain context. Go one section at a time and wait for my answer before moving on.

Cover, in order:

1. **About me** — name, role, main field, languages, frameworks, tools, strengths, what I want to improve, how I like to work, what I dislike.
2. **Projects** — for each active project: name, short description, the problem it solves, target users, tech stack, current status, next steps.
3. **AI instructions** — how you should respond, and anything you should avoid.
4. **Coding style** — naming, structure, error handling, and what to avoid in code.
5. **Current focus** — what I am working on right now.
6. **Decisions** — any decisions already made, with a short reason for each.

After each section, write the answers into the matching file in `brain/`. Keep the files short and practical. If I skip something, leave a placeholder and move on.
