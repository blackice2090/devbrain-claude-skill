# Prompt: Compress

A manual prompt to shorten a `brain/` file that has grown too long. Copy it into Claude Code.

---

Read `brain/<file>.md` and produce a shorter version.

Rules:

- Keep all genuinely useful context and the file's structure (headings).
- Remove repetition, filler, and anything outdated.
- Merge points that say the same thing.
- Do not invent new information.
- Aim for clearly shorter while staying practical.

Show me the shortened version and a one-line note on what you removed before saving it.
